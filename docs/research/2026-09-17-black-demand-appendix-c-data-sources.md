# Proxy data sources for a Denver Uber Black demand heatmap — evaluated 2026-09-17

**Recommended v1 (free-first):** Census ACS 2020-2024 tract/block-group income (free key, now mandatory) + Census cartographic polygons; a hand-curated luxury-hotel/FBO/generator list geocoded with Places Text Search (Pro SKU, 5,000 free/month) — not OSM (0 of 366 metro hotels carry a `stars` tag); BTS On-Time data (free) for DEN hour×day-of-week flight baselines; Open-Meteo (free) hourly weather; scraped Colorado Convention Center + Red Rocks + DCPA calendars (no feeds exist); NWSS fixed dates. Pay only if a live 7-day flight schedule is required: AeroAPI `/schedules` ≈ $78/month at DEN volume.

All links checked 2026-09-17. "UNVERIFIED" = no URL could be opened for that claim.

## Cheapest path to "flights per hour at DEN, next 7 days"
1. **Free baseline:** BTS On-Time (last 13 months) → bin `CRSDepTime`/`CRSArrTime` by hour × DOW × month for Origin=DEN and Dest=DEN; scale by T-100 Segment (All Carriers) seats for the same month last year and by DEN's monthly passenger PDF (manual). Caveat: On-Time is domestic-only, so add the international bank as a constant from T-100 International Segment (departures performed ÷ days) placed in DEN's known morning/evening international windows (windows UNVERIFIED — derive from one AeroAPI `/schedules` sample). Hub banks are stable week to week, so this yields a defensible 7-day forecast; refresh monthly. It is also the outage fallback.
2. **Live overlay (optional, ≈$78/mo):** AeroAPI `/schedules/{today}/{today+7d}?origin=KDEN&include_codeshares=false` plus `destination=KDEN`, weekly; response carries `aircraft_type` (ICAO code, verified in the OpenAPI spec) for seat weighting. Personal tier is the right tier (Standard has a $100/mo minimum); its 10 result-sets/min cap makes the ~900-set weekly pull take ≈90 min — fine for a cron. First try AeroDataBox's free RapidAPI tier (400 units) to confirm FIDS future depth — if it reaches +7 days it undercuts AeroAPI ~4×.

## Caveats found while verifying
- Census API key is mandatory as of today; keyless code silently receives HTML.
- Denver Open Data ACS layers stop at 2017-2021 — use the Census API.
- OSM has zero hotel `stars` tags in the metro — never build a luxury filter on it.
- Alias table needed: Kimpton Hotel Born → Limelight Denver; JW Marriott Cherry Creek → Hotel Clio.
- flydenver.com blocks non-browser fetches (Cloudflare "Just a moment").
- OpenSky's departures doc says the window "must cover more than two days (UTC)" — a doc bug; either way the data is D-1.
